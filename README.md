# Alma-Zen

Sistema de inventario para almacenes, desarrollado como plugin de WordPress.

## Características

- Roles de usuario: **Administrador** (CRUD de productos) y **Usuario** (lectura).
- Productos categorizados.
- Precios por unidad o por kilo.
- Interfaz modular y escalable.
